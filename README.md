## What it does

`main.py` writes one out-of-office email auto-reply — a single sentence, 154 characters — to `/output/entry.txt`:

> I'm out of the office until Monday, and the honest version is that I am on holiday because work had me running on empty, and I'll reply once I'm refilled.

It admits the private truth (the holiday is recovery from burnout, not a vacation) while staying warm and professional enough that a manager would let it stand.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
